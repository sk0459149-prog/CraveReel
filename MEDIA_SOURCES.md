## Verified recipe videos

The following seeded recipes have dish-specific YouTube recipe videos attached: Kadhai Paneer, Shahi Paneer, Dal Makhani, Punjabi Chole, Palak Paneer, Pav Bhaji, Aloo Gobi, Masala Dosa, Chicken Dum Biryani, Fettuccine Alfredo, Smash Burger, Chocolate Lava Cake, Hakka Noodles, Margherita Pizza, and Japanese Souffle Pancakes.

The berry smoothie bowl keeps the existing video URL because a matching YouTube video source was not verified during this update.

## Existing databases

On startup, the initializer repairs the verified media mappings on seeded recipes. It also removes duplicate copies of the project's seeded catalog recipes while preserving the newest copy, which contains the corrected media.

## Licensing / attribution

Wikimedia Commons files have file-specific licenses. Keep the attribution/license information from the relevant Commons file pages when redistributing the project. YouTube videos remain hosted by YouTube and are embedded/linked rather than copied.
